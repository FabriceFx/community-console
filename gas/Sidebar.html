Configuration IA (Gemini)

Cette clé permet à l'extension Chrome de générer automatiquement un résumé des questions.

Secret partagé (obligatoire)

La WebApp est publiée en accès « N'importe qui » : ce secret est la seule barrière empêchant un tiers qui connaîtrait votre URL de consommer votre quota Gemini.

Recopiez-le ensuite dans l'extension Chrome.

Signature

Le nom apposé au bas de chaque message généré, dans toutes les langues.

Laissez vide pour ne pas signer : le message s'arrête alors sur sa formule de clôture.

Formules de clôture

La phrase qui précède votre signature. Écrivez les vôtres : une par ligne, tirées au hasard sans répétition immédiate.

Un tiret seul (-) sur une ligne = aucune formule, le message s'arrête sur le fond.

Liaison avec l'Extension

Pour faire le lien avec l'extension Chrome, vous devez publier ce projet comme une Application Web (WebApp).

Assurez-vous que l'accès est défini sur "N'importe qui" ou "Moi-même", selon votre usage.
